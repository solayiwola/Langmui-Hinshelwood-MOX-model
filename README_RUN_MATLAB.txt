L-H + Heterojunction CO Selectivity Numerical Model

How to run in MATLAB
1. Unzip the folder.
2. Open MATLAB.
3. Set the current folder to: LH_Heterojunction_MATLAB_Model/matlab
4. Run:

   LH_Heterojunction_CO_Selectivity_RunAll

The MATLAB script will create:
- results_matlab/ : calculated CSV result tables
- figures_matlab/ : PNG graphs and maps

Already-computed outputs are also included in:
- results/ : equation-identical computed tables
- figures/ : thesis-ready PNG graphs

Important modelling note:
Some kinetic and interfacial coefficients are literature-constrained modelling coefficients.
They should be calibrated later using experimental conductance transients or dedicated DFT/NEB calculations.
